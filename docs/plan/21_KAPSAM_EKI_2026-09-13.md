# 6. Güncel Kapsam Dışı, Ertelenen ve İptal Edilen Özellikler

> **Owner Override — Güncel kapsam kararı**
>
> Bu bölüm, mevcut geliştirme döngüsü için önceki planlarda yer alan çelişkili kapsam maddelerinin önüne geçer.  
> Burada **ertelendi**, **MVP dışı** veya **iptal edildi** olarak işaretlenen hiçbir özellik; çekirdek ürünün tamamlanma kriteri, faz geçiş şartı veya release blocker olarak değerlendirilmemelidir.

# 8. Completion Kuralı

Bu plan açısından **“implementation tamamlandı”** denebilmesi için:

- Çekirdek kapsamın user-facing akışları gerçekten çalışmalı.
- Core feature'lar yalnızca kodda bulunmamalı; kullanıcı tarafından erişilebilir ve test edilmiş olmalı.
- Bilerek ertelenen maddeler eksik sayılmamalı.
- İptal edilen özellikler hiçbir şekilde geri eklenmemeli.
- Store/web operasyonları implementation tamamlanma hesabına dahil edilmemeli.
- Feature gate ile kapatılmış ve bu bölümde ertelenmiş entegrasyonlar, owner'ın yeni kararı olmadan yeniden açılmamalı.
- “Deferred” bir madde, gelecekte yapılacak iş olarak kayıtlı kalmalı; ancak mevcut core implementation fazını bloke etmemeli.
